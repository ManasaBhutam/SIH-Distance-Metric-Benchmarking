INTERPRETATION GUIDANCE
-----------------------------------------------------------------
Model A uses all eight original features.
Model B excludes LFSTAT.
Model C uses AGE, BAIND and N2BAMED only.

Silhouette scores measure separation within each model's own distance matrix. They are not directly comparable as proof that one feature set is universally better.

Cluster balance is the smallest cluster size divided by the largest cluster size. Higher values indicate more balanced cluster sizes.

ARI measures agreement between two cluster assignments. A low or negative ARI indicates little agreement.

Model C removes the selected employment-related variables, but the interpretation of BAIND and N2BAMED should still follow the NSCG codebook. Missing values and logical skips must not automatically be interpreted as meaningful groups.

These experiments use a 3,000-record sample and two-cluster hierarchical clustering. Findings should be validated before generalizing to the full NSCG population.
